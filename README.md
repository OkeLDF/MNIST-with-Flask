Open the link below. Draw a digit (a number from 0 to 9) and click on 'Predict' to see the results from the RandomForestClassifier model trained on the (augmented) MNIST dataset.

https://okeldf.pythonanywhere.com

Note: Data augmentation was done using the original MNIST dataset plus the dataset shifted 3 pixels to left, right, up and down. For each direction shifting, 1/4 of the images were used, resulting in a final dataset twice the size of the original dataset.
